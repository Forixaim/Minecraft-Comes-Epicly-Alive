# Mod Focus
This mod focuses on bringing a proper integration with MCA Reborn entities (no items yet). Using a multi-layer renderer on an Entity Patch Renderer, rendering MCA villagers is now possible and now combat on guards will feel the same as players.

# Features
MCEA currently comes with basic Entity Patching on MCA Villagers, giving them the same animation freedom as players with Epic Fight installed. Allowing better and more fluid combat systems and later down the line, more advanced AI that makes villagers rival bosses (If I ever go down that route).

(WIP) The Staff of Life and the Scythe will be having unique use animations and maybe a moveset down the line.

(WIP) Disabled **Friendly Fire**, **Epic Fight** attacks cover large areas giving players the opportunity to accidentally hit a villager while trying to fight off a zombie horde with the guards, with FF off later via a player menu, Friendly Fire on MCA villagers will be the least of a player's concern.
